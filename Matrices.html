06. Matrices

Cuestionario de Autoevaluación

Responde las preguntas y presiona el botón al final para validar tus conocimientos.

1. Si una condición dice: SI (edad >= 18) ENTONCES, ¿qué camino toma el programa si el usuario tiene 15 años?
2. ¿Qué operador lógico requiere que DOS condiciones se cumplan obligatoriamente al mismo tiempo para ser verdadero?
3. ¿Qué estructura de control se utiliza para repetir un bloque de código mientras una condición sea verdadera?
4. ¿Qué estructura de control se utiliza de forma anidada (uno dentro de otro) para recorrer por completo una matriz?
5. Si una matriz representa una tabla, ¿cuál de los dos ejes se recorre generalmente primero en la lógica estándar?
